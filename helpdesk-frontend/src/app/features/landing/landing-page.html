1. Responsable del tratamiento

Soportix es una plataforma de mesa de ayuda orientada a la gestión de solicitudes y tickets de soporte técnico para equipos y organizaciones.

2. Datos recopilados

Para la prestación del servicio se procesan exclusivamente los datos necesarios para la autenticación y resolución de incidencias:

  • Nombre de usuario y dirección de correo electrónico corporativo o personal.
  • Contraseñas almacenadas bajo cifrado unidireccional estándar (hash PBKDF2/SHA256).
  • Contenido de los tickets, comentarios y archivos adjuntos cargados voluntariamente por los usuarios.
  • Calificaciones de satisfacción del servicio (CSAT) asociadas a tickets cerrados.

3. Uso de cookies y sesiones

Soportix utiliza únicamente identificadores técnicos de sesión y tokens de autenticación segura (JWT) almacenados localmente para mantener activa la sesión del usuario. No se utilizan cookies de terceros ni rastreadores publicitarios.

4. Conservación y confidencialidad

La información contenida en las conversaciones de soporte es confidencial y solo accesible por los agentes asignados, administradores de la organización y el usuario creador del ticket según el control de acceso basado en roles (RBAC).

1. Objeto del servicio

Soportix provee una herramienta de software como servicio para la recepción, asignación, seguimiento y resolución de tickets de soporte técnico e incidencias operativas.

2. Cuentas y roles de usuario

El acceso al sistema se segmenta en tres perfiles definidos:

  • Usuario final: Creación de tickets propios, visualización del estado y envío de calificaciones.
  • Agente de soporte: Atención de tickets asignados, uso de respuestas rápidas y actualización de estados de resolución.
  • Administrador: Configuración global de categorías, gestión de usuarios y consulta de métricas de rendimiento.

3. Uso aceptable

Los usuarios se comprometen a utilizar la mesa de ayuda de manera responsable, evitando la carga de archivos maliciosos, contenido que vulnere la propiedad intelectual o datos sensibles innecesarios para la resolución del soporte.

4. Modo demostración

Las sesiones iniciadas mediante el modo "Probar demo" operan bajo una cuenta de solo lectura para la exploración de la interfaz, con restricciones automáticas de modificación de datos.

} @else if (legalModal() === 'security') {

1. Seguridad de las comunicaciones

Todo el tráfico entre el navegador y los servidores de Soportix viaja encriptado mediante el protocolo HTTPS con certificados TLS 1.3 vigentes.

2. Autenticación y control de acceso

Las peticiones a la API están protegidas mediante tokens JWT firmados criptográficamente, con expiración automática y verificación estricta de permisos por rol en cada endpoint.

3. Gestión de archivos adjuntos

Los archivos y capturas anexados a los tickets son validados por extensión y tamaño antes de su almacenamiento seguro en la nube, restringiendo su descarga a usuarios autorizados.

4. Integridad de la base de datos

La base de datos relacional opera con respaldos programados, aislamiento de entornos y protección contra inyecciones SQL a través del ORM del backend.
